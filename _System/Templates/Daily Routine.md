# Daily routine · {{date:YYYY-MM-DD}}

> [!note] From lesson [[4.4 Daily Routine- Before, During, After|4.4]]. Tick it every day for two weeks, even on days with no trades.

## Before (20–30 min)
- [ ] **State check.** Sleep, mood, stress, health: 1–5 → ___ (at 4–5: half size or no trading)
- [ ] **Event calendar.** Big releases today in UTC+7, and no-trade windows around them: 
- [ ] **HTF state** for each market (up / down / range / unclear): 
- [ ] **Mark zones** in the trend direction and **set price alerts** at their edges
- [ ] **Today's if-then plan** (1–2 lines): *If … and … then …; otherwise nothing.*

## During (only when an alert fires)
- [ ] Alert fires → open the LTF → run the if-then checklist (4.3)
- [ ] All ticks → size (3.2), enter, place the stop **immediately**, set the target
- [ ] Manage only as the plan says (3.5); no alert = no screen time

## After (~15 min)
- [ ] **Journal every trade** with entry and exit screenshots (4.5)
- [ ] **Grade the execution** A / B / C, whatever the result
- [ ] **Note emotions** at entry and exit
- [ ] **Update equity peak and drawdown** (3.6); any circuit breaker for tomorrow?
- [ ] **Close the platform.** The trading day is over.
