# กิจวัตรประจำวัน · {{date:YYYY-MM-DD}}

> [!note] จากบทเรียน [[4.4 Daily Routine- Before, During, After|4.4]] ติ๊กทุกวันเป็นเวลาสองสัปดาห์ แม้วันที่ไม่มีเทรด

## ก่อน (20–30 นาที)
- [ ] **เช็กสภาพตัวเอง** การนอน อารมณ์ ความเครียด สุขภาพ: 1–5 → ___ (ถ้าได้ 4–5: ครึ่งไม้หรือไม่เทรด)
- [ ] **ปฏิทินเหตุการณ์** ข่าวใหญ่วันนี้ตามเวลา UTC+7 และช่วงห้ามเทรดรอบ ๆ: 
- [ ] **สภาวะ HTF** ของแต่ละตลาด (ขึ้น / ลง / กรอบ / ไม่ชัด): 
- [ ] **มาร์กโซน** ในทิศทางเทรนด์ และ **ตั้งแจ้งเตือนราคา** ที่ขอบโซน
- [ ] **แผนถ้า-แล้วของวันนี้** (1–2 บรรทัด): *ถ้า … และ … แล้ว …; ไม่อย่างนั้นไม่ทำอะไร*

## ระหว่าง (เมื่อแจ้งเตือนดังเท่านั้น)
- [ ] แจ้งเตือนดัง → เปิด LTF → ไล่เช็กลิสต์ถ้า-แล้ว (4.3)
- [ ] ติ๊กครบ → คำนวณขนาด (3.2) เข้า วาง Stop **ทันที** ตั้งเป้าหมาย
- [ ] บริหารตามที่แผนบอกเท่านั้น (3.5) ไม่มีแจ้งเตือน = ไม่ต้องดูจอ

## หลัง (~15 นาที)
- [ ] **บันทึกทุกเทรด** พร้อมภาพหน้าจอตอนเข้าและตอนออก (4.5)
- [ ] **ให้เกรดการลงมือ** A / B / C ไม่ว่าผลลัพธ์จะเป็นอย่างไร
- [ ] **จดอารมณ์** ตอนเข้าและตอนออก
- [ ] **อัปเดตจุดสูงสุดของพอร์ตและ Drawdown** (3.6) มีเบรกเกอร์ไหนทำงานสำหรับพรุ่งนี้ไหม?
- [ ] **ปิดแพลตฟอร์ม** วันเทรดจบแล้ว
