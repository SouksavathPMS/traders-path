## 2.1 [[2.1 Swings- HH, HL, LH, LL|สวิง: HH, HL, LH, LL]]

จุดสวิงสูง / จุดสวิงต่ำ (Swing high / Swing low)::ยอด / จุดต่ำที่ราคากลับตัว
ขาแรงส่ง (Impulse leg)::การขยับในทิศทางของฝ่ายที่คุมเกม มักยาวและเร็วกว่า
การย่อ (Pullback / Correction)::การขยับสวนทาง มักสั้นและช้ากว่า
HH / HL::จุดสูงที่สูงขึ้น / จุดต่ำที่สูงขึ้น: ผู้ซื้อคุมเกม
LH / LL::จุดสูงที่ต่ำลง / จุดต่ำที่ต่ำลง: ผู้ขายคุมเกม
บีบตัว / ขยายตัว (Contraction / Expansion)::LH + HL (การบีบ) / HH + LL (แกว่งแรง ไม่มีใครคุม)
Fractal (กฎ 5 แท่ง)::จุดสวิงสูงอยู่เหนือ 2 แท่งทั้งสองข้าง จุดสวิงต่ำอยู่ใต้ 2 แท่งทั้งสองข้าง
สวิงที่ยืนยันแล้ว (Confirmed swing)::สวิงที่ 2 แท่งด้านขวาปิดแล้ว
สวิงหลัก / สวิงย่อย (Major / Minor swing)::จุดกลับตัวที่มีความหมาย / การหยุดพักเล็ก ๆ ภายในขาราคา
Bar replay::เครื่องมือในแพลตฟอร์มที่ซ่อนอนาคตและเล่นแท่งเทียนทีละแท่ง

## 2.2 [[2.2 Trends, Ranges & Market Cycles|เทรนด์ ไซด์เวย์ และวัฏจักรตลาด]]

เทรนด์ (Trend)::ตลาดที่ทำ HH + HL (ขึ้น) หรือ LH + LL (ลง) *(ดู 2.1)*
กรอบราคา (Range)::ราคาวิ่งระหว่างเพดานและพื้นที่ค่อนข้างแบน
สมดุล / ไม่สมดุล (Balance / Imbalance)::ผู้ซื้อและผู้ขายเห็นตรงกันเรื่องมูลค่า / ฝ่ายหนึ่งเร่งรีบกว่า *(ดู 7.1)*
การทะลุ (Breakout)::ราคาปิดนอกกรอบราคาหรือเลยระดับสำคัญ
เทรนด์แข็งแรง vs เหนื่อย (Healthy vs tired)::แรงส่งแรงและการย่อตื้น vs แรงส่งหดลงและการย่อลึกขึ้น
วัฏจักรไวคอฟฟ์ (Wyckoff cycle)::สะสม → ขาขึ้น → แจกจ่าย → ขาลง
การสะสม / การแจกจ่าย (Accumulation / Distribution)::ผู้เล่นรายใหญ่ซื้อ / ขายภายในกรอบราคา
Markup / Markdown::ช่วงเทรนด์ขึ้น / ลงหลังกรอบราคา
การสะสมซ้ำ (Re-accumulation)::กรอบราคาภายในขาขึ้นที่นำไปสู่การไปต่อ

## 2.3 [[2.3 Break of Structure & Change of Character|BOS และ CHoCH]]

Swing high / Swing low::จุดกลับตัวของราคา *(ดู 2.1)*
HH / HL / LH / LL::Higher high / Higher low / Lower high / Lower low *(ดู 2.1)*
BOS (Break of structure)::แท่งเทียนปิดเลย Swing ล่าสุด **ใน** ทิศทางของเทรนด์
CHoCH (Change of character)::แท่งเทียนปิดเลย Swing ที่ถูกปกป้องเป็นครั้งแรก **สวน** เทรนด์
MSS (Market structure shift)::ชื่อที่ ICT ใช้เรียก CHoCH ที่ตามหลังการกวาดสภาพคล่อง *(ดู 5.2)*
Protected low / high::HL (หรือ LH) ที่เป็นจุดเริ่มของ HH (หรือ LL) ล่าสุด แนวป้องกันสำคัญของเทรนด์
การยอมรับ / การปฏิเสธ (Acceptance / Rejection)::ราคาปิดและอยู่เลยระดับได้ / แค่ไส้ทะลุแล้วปิดกลับเข้ามา
Trailing stop::เลื่อน Stop ขึ้นตามหลัง Protected low ใหม่แต่ละจุดเมื่อเทรนด์ไปต่อ
HTF / LTF::ไทม์เฟรมสูง / ต่ำ *(ดู 1.5, 2.6)*

## 2.4 [[2.4 Support, Resistance & Role Reversal|แนวรับ แนวต้าน และการสลับบทบาท]]

แนวรับ / แนวต้าน (Support / Resistance, S/R)::โซนราคาที่ผู้ซื้อ / ผู้ขายเคยหยุดราคา
โซน (Zone)::แถบราคา ไม่ใช่เส้นเดียว จากปลายไส้ถึงจุดที่ตัวแท่งกระจุกตัว
การทดสอบ (Test)::ราคากลับมาที่ระดับนั้น
การซ้อนทับของเหตุผล (Confluence)::มีหลายเหตุผลที่ราคาเดียวกัน (เลขกลม จุดสูงเดิม การสลับบทบาท)
การสลับบทบาท (Role reversal)::แนวต้านที่แตกกลายเป็นแนวรับ หรือแนวรับที่แตกกลายเป็นแนวต้าน
Bounce::เทรดการปฏิเสธที่ระดับราคาในทิศทางเทรนด์
Break & retest::เทรดการย่อครั้งแรกกลับมาที่ระดับที่แตกด้วยราคาปิด
การทะลุหลอก (Failed break)::ราคาแทงไส้ทะลุระดับแต่ปิดกลับเข้ามา *(ดู 5.2)*
เลขกลม (Round number)::ราคาอย่าง 100, 1.1000 หรือ 2,000 ที่คนจำนวนมากจับตา

## 2.5 [[2.5 Supply & Demand Zones|โซนอุปสงค์และอุปทาน]]

โซน Demand / Supply::บริเวณราคาที่ผู้ซื้อ / ผู้ขายรายใหญ่น่าจะทิ้งคำสั่งที่ยังไม่ได้เติมไว้
ฐาน (Base)::แท่งเทียนเล็ก 1–3 แท่งที่ราคาหยุดพักก่อนวิ่งแรง
ขาเข้า / ขาออก (Leg-in / Leg-out)::การวิ่งเข้าสู่ฐาน / การวิ่งแรงออกจากฐาน
RBR, DBR, RBD, DBD::Rally-base-rally, Drop-base-rally, Rally-base-drop, Drop-base-drop (รูปแบบโซนสี่แบบ)
เส้น Proximal / Distal::ขอบโซนที่ใกล้ราคาปัจจุบัน (จุดเข้า) / ขอบไกล (Stop อยู่เลยออกไป)
ยังสด (Fresh)::ยังไม่เคยถูกกลับมาทดสอบตั้งแต่เกิด
การออกจากฐาน (Departure)::ราคาออกจากฐานเร็วและแรงแค่ไหน
BOS::การทะลุโครงสร้าง *(ดู 2.3)*
Confluence (จุดบรรจบ)::หลายเหตุผลที่ตรงกันที่ราคาเดียว
การเข้าแบบรอยืนยัน (Confirmation entry)::รอ CHoCH บน LTF ภายในโซนก่อนเข้า *(ดู 2.6)*
R / R:R::หน่วยความเสี่ยงและผลตอบแทนต่อความเสี่ยง *(ดู 3.3)*

## 2.6 [[2.6 Multi-Timeframe Structure|โครงสร้างหลายไทม์เฟรม]]

HTF / MTF / LTF::ไทม์เฟรมใหญ่ / กลาง / เล็ก *(ดู 1.5)*
โครงสร้างซ้อนกัน (Nested structure)::เทรนด์ LTF ที่ครบสมบูรณ์อยู่ภายในแต่ละขาของ HTF
ทิศทางที่เลือก (Bias)::ทิศทางที่อนุญาตให้เทรด กำหนดโดย HTF
โซน HTF (HTF zone)::ระดับราคาบน HTF: Protected HL, แนวรับแนวต้าน หรือ Demand/Supply *(ดู 2.3–2.5)*
CHoCH (Change of character)::การปิดครั้งแรกเลยสวิงที่ปกป้องเทรนด์ *(ดู 2.3)*
BOS (Break of structure)::การปิดเลยสวิงในทิศทางเทรนด์ *(ดู 2.3)*
ความสอดคล้อง (Alignment)::HTF และ LTF ชี้ไปทางเดียวกัน
เลื่อน Stop ตาม (Trailing a stop)::เลื่อน Stop ตามจุดสวิงต่ำใหม่ (ในไม้ซื้อ) ขณะที่เทรดไปได้ดี

## 2.8 [[2.8 Indicators- Moving Averages, RSI, MACD, ATR, Volume|อินดิเคเตอร์: ค่าเฉลี่ยเคลื่อนที่ RSI MACD ATR และวอลุ่ม]]

อินดิเคเตอร์ (Indicator)::ตัวเลขที่คำนวณจากราคาและ/หรือวอลุ่มในอดีต แสดงบนหรือใต้กราฟ
ความล่าช้า (Lag)::ระยะเวลาระหว่างที่ราคาเปลี่ยนจนอินดิเคเตอร์แสดงการเปลี่ยนนั้น
SMA (Simple moving average)::ค่าเฉลี่ยของราคาปิด *n* แท่งล่าสุด *(ดู 9.5)*
EMA (Exponential moving average)::ค่าเฉลี่ยเคลื่อนที่ที่ให้น้ำหนักราคาปิดล่าสุดมากกว่า จึงช้าน้อยกว่า
การตัดกัน (Crossover)::เส้นหนึ่งตัดอีกเส้น เช่น ค่าเฉลี่ยเร็วตัดค่าเฉลี่ยช้า
ออสซิลเลเตอร์ (Oscillator)::อินดิเคเตอร์ที่เคลื่อนในกรอบ (เช่น 0–100) อย่าง RSI
RSI (Relative strength index)::เทียบขนาดการขึ้นกับการลงช่วงหลัง ในสเกล 0–100
ซื้อมากเกินไป / ขายมากเกินไป (Overbought / Oversold)::RSI เหนือ 70 / ต่ำกว่า 30 เป็นคำอธิบายการขยับแรงช่วงหลัง ไม่ใช่สัญญาณกลับตัว
MACD (Moving average convergence divergence)::ระยะห่างระหว่าง EMA เร็วกับ EMA ช้า พร้อมเส้นสัญญาณและฮิสโตแกรม
ATR (Average true range)::ขนาดเฉลี่ยของแท่งเทียนช่วงหลังรวม Gap *(ดู 3.5)*
True range::ค่ามากที่สุดของ: สูงสุด − ต่ำสุด, |สูงสุด − ราคาปิดก่อนหน้า|, |ต่ำสุด − ราคาปิดก่อนหน้า|
วอลุ่ม / วอลุ่มสัมพัทธ์ (Volume / Relative volume)::ปริมาณที่ซื้อขาย / วอลุ่มวันนี้หารด้วยค่าเฉลี่ยช่วงหลัง
การแตกต่าง (Divergence)::ราคาทำจุดสุดโต่งใหม่ แต่อินดิเคเตอร์ไม่ทำ *(ดู 6.1, 7.4)*

## 2.9 [[2.9 Classic Chart Patterns- Double Tops, Head & Shoulders, Triangles, Flags|รูปแบบกราฟคลาสสิก: ยอดคู่ หัวไหล่ สามเหลี่ยม ธง]]

รูปแบบกราฟ (Chart pattern)::รูปร่างของสวิงที่จำได้ ซึ่งมักเกิดก่อนการขยับแบบหนึ่ง
รูปแบบกลับตัว / รูปแบบต่อเนื่อง (Reversal / Continuation pattern)::แบบที่มักจบเทรนด์ / แบบที่พักเทรนด์ก่อนไปต่อ
เส้นคอ (Neckline)::เส้นแนวรับ (หรือแนวต้าน) ที่การหลุดยืนยันรูปแบบ
การยืนยัน (Confirmation)::แท่งเทียน **ปิด** เลยเส้นคอหรือเส้นแนวโน้ม *(ดู 2.3)*
ยอดคู่ / ก้นคู่ (Double top / Double bottom)::ยอด (ก้น) สองครั้งที่ราคาใกล้กัน คั่นด้วยก้น (ยอด)
หัวไหล่ (Head and shoulders, H&S)::ยอดสามยอด ยอดกลางสูงที่สุด แบบกลับหัวคือรูปแบบก้น
สามเหลี่ยม (Triangle: สมมาตร / ขาขึ้น / ขาลง)::เส้นแนวโน้มที่บีบเข้าหากัน ขาขึ้น = ยอดแบนและจุดต่ำที่สูงขึ้น
ธง / ธงสามเหลี่ยม (Flag / Pennant)::การพักสั้น ๆ แคบ ๆ สวนการขยับที่แรง ("เสาธง")
เป้าวัดระยะ (Measured move)::ความสูงของรูปแบบที่ฉายจากจุดทะลุ
การย่อกลับ (Pullback / Throwback)::ราคากลับมาที่เส้นคอที่ถูกทะลุหลังการทะลุ
อัตราล้มเหลวที่จุดคุ้มทุน (Break-even failure rate)::ในงานศึกษาของ Bulkowski คือ % ของรูปแบบที่ราคาไม่ขยับอย่างน้อย 5% ในทิศทางที่ทะลุ
